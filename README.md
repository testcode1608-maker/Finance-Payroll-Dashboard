# Finance & Payroll Dashboard

A responsive React + TypeScript + Vite dashboard inspired by the reference Reel: soft ivory canvas, sage-green navigation, colorful finance cards, compact transaction lists, and clean typography.

## Features
- Responsive dashboard with collapsible mobile navigation
- Money overview, cards, transactions, budgets and dues sections
- Interactive search and navigation
- Add-card modal and card live toggles
- Recharts spending overview
- Light, calm palette and subtle hover animations

## Run locally
Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## GitHub Pages
This is a Vite single-page app. For GitHub Pages, configure the Vite `base` option to `'/Finance-Payroll-Dashboard/'` before deploying, or use a deployment workflow that sets the correct base path.

All dashboard entries are demo data for frontend preview only; no backend or real financial data is connected.
